# Збірка APK і перевірка на телефоні

Мета цієї перевірки — якомога раніше побачити, як гра поводиться на справжньому Android: чи плавний стрибок, чи швидко реагує тап, скільки fps. Браузер на комп'ютері цього не покаже: WebView на телефоні середнього класу помітно слабший.

## Що потрібно один раз

1. **Node.js 22** (LTS) — https://nodejs.org. Перевірка в терміналі: `node -v` → `v22.x`.
2. **Android Studio** (свіжа стабільна версія) — https://developer.android.com/studio.
   Під час першого запуску погодься встановити Android SDK; JDK уже вбудований у Studio.
3. Телефон з Android і USB-кабель (або можна передати APK-файл будь-яким способом).

## Збірка

У терміналі в папці проєкту (`D:\Soft\DEV\slime-climb`):

```bash
npm i                  # залежності (повторювати, коли змінився package.json)
npm run android:sync   # збирає гру в dist/ і копіює її в android-проєкт
npx cap open android   # відкриває android/ в Android Studio
```

В Android Studio:

1. Дочекайся, поки внизу закінчиться **Gradle sync** (перший раз — кілька хвилин, качає залежності).
2. Меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
3. Коли з'явиться сповіщення «APK(s) generated», натисни **locate**. Файл:
   `android/app/build/outputs/apk/debug/app-debug.apk`.

Важливо: після кожної зміни коду гри знову запускай `npm run android:sync`, інакше в APK піде стара версія.

## Встановлення на телефон

- **Через кабель:** увімкни на телефоні «Параметри розробника» → «Налагодження USB», підключи телефон і натисни ▶ Run в Android Studio — застосунок встановиться і запуститься сам.
- **Файлом:** скопіюй `app-debug.apk` на телефон і відкрий його. Android попросить дозволити «Встановлення з невідомих джерел» для застосунку, яким ти відкриваєш файл (файловий менеджер, Telegram тощо) — дозволь.

Це debug-збірка: вона підписана тестовим ключем і годиться лише для перевірки, не для Google Play.

## Як подивитись fps

У `src/main.js` тимчасово заміни `const DEBUG = false;` на `const DEBUG = true;`, потім `npm run android:sync` і збери APK заново. У лівому нижньому куті з'явиться лічильник кадрів. Після перевірки поверни `false`.

У браузері те саме вмикається без перезбірки: `npm run dev` і адреса з `?debug=1` в кінці.

## Що перевірити і що мені написати

1. **Плавність стрибка** — дуга без ривків і «смикань»?
2. **Відгук тапу** — стрибок починається одразу після дотику, чи є відчутна затримка?
3. **fps** — яке число здебільшого (мета — стабільні ~60) і чи просідає воно під час стрибка.
4. **Згорни застосунок і поверни** — гра має стояти на паузі з кнопкою «Продовжити», нічого не має «перестрибнути».
5. **Модель телефону** — щоб розуміти, на якому залізі ці цифри.

Чесне застереження: зараз на екрані лише стіни і слизак. Якщо вже тут fps нижчий за 55, з ворогами й снарядами буде гірше — тоді доведеться спростити графіку або налаштування рендеру ще до наступних етапів.
