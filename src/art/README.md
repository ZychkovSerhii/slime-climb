# Арт гри

Уся графіка намальована кодом і лежить тут. Код гри знає лише ключі текстур (`slime`, `bat`…) і назви анімацій (`slime:idle`), тож будь-який спрайт можна перемалювати або замінити, не чіпаючи логіку.

| Що | Де |
|---|---|
| Кольори біому | `palette.js` |
| Спрайт: сітки кадрів, палітра, анімації | `sprites/<key>.js` (один файл — одна істота) |
| Список спрайтів | `sprites/index.js` |
| Фон біому | печера `backgrounds/slimeCave.js`, зима `backgrounds/winterNight.js` (параметри в `CFG`) |
| Зима: стіна `wallIce`, бурулька `icicle` (той самий розмір, що `wall`/`spike`), `elf`, `candy`, `bear` (кадр `rear` — ричить), `penguin`, `santa`, `gift`, `snowflake` | `sprites/<key>.js` |
| Готові PNG замість намальованого | `png/<key>.png` |
| Зброя на слизакові: `axe`, `shotgun`, вени чакри `chakraVeins` | `sprites/<key>.js`; розмах сокири малює `entities/WeaponView.js` |
| Солом'яна шляпа `hat`, кірка льоду `frost` (поверх замороженого ворога, масштабується під його розмір) | `sprites/<key>.js` |
| Скіни магазину: `skinAssassin`, `skinCommander`, `skinRaccoon`, `skinMurzik` (той самий розмір і кадри `idle1/idle2/jump`, що в `slime`; ціни й назви — `BALANCE.meta.skins`) | `sprites/<key>.js` |
| Генерація текстур і анімацій у Phaser | `textures.js` (зазвичай не чіпати) |

## Перемалювати спрайт у коді

Відкрий `sprites/<key>.js`. Кадр — це масив рядків однакової довжини. Кожен символ означає колір із `palette` спрайта, а `.` — прозорість. Одна клітинка дорівнює `cell` пікселів (зазвичай 4).

- Сітка мусить влазити в полотно `w × h`. Якщо вона менша, її буде вирівняно по центру.
- **Не міняй `w` і `h`:** від них залежать хітбокси, а отже баланс.
- Анімація — це список назв кадрів і `fps`. Назви анімацій, які викликає код (`idle`, `jump`, `run`, `bite`, `fly`, `shoot`, `crawl`, `legs`), мусять лишитися.
- `outline(rows)` з `grid.js` автоматично додає темний контур.
- `npm test` ловить помилки: нерівні рядки, колір без палітри, сітку, що не влазить, анімацію з неіснуючим кадром.

## Замінити готовим малюнком (Aseprite, Piskel тощо)

1. Намалюй кадри одного спрайта в один рядок, зліва направо. Порядок кадрів — як у `frames` у файлі спрайта. Розмір кожного кадру — рівно `w × h` зі спрайта.
2. Збережи як `png/<key>.png`, наприклад `png/bat.png`: два кадри по 40×28, тобто файл 80×28.
3. Перезбери гру (`npm run build`). Збірка сама знайде файл, правити код не треба.

Якщо розмір файлу не збігається, гра попередить у консолі й візьме намальований кодом спрайт, тож гра не зламається.

Фон замінюється файлом `png/bg.png` (зима — `png/bgWinter.png`) будь-якого розміру. Він тайлиться, тому краї мають стикуватися.
