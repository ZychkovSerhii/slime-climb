## Як працюємо
- Стек: Phaser 4 + Vite + Capacitor 8 (Android). Node ≥ 22.
- Кожен етап — гілка `feat/v2-NN-…`, PR у `main`, окремий APK. Старі версії не губимо.
- Користувач хоче, щоб Claude зливав PR сам. Якщо автоперевірка блокує, не обходь її: попроси користувача.
- APK збирає CI (`.github/workflows/android-apk.yml`) на кожен пуш у `main`, `feat/**` чи `fix/**` і кладе в реліз `apk-dev`. Завантажити: `gh api -H "Accept: application/octet-stream" repos/ZychkovSerhii/slime-climb/releases/assets/<id>` (id беремо з `releases/tags/apk-dev`).
- Перевірки: `npm test`, `npm run build`, бот-плейтест `node scripts/playtest.mjs --seconds 220 --runs 2`. Playwright у хмарі: `executablePath` на `/opt/pw-browsers/chromium-*/chrome-linux*/chrome`.
- Локальна копія: `D:\Soft\DEV\slime-climb`. Користувач має Git і Android Studio і робить `git pull`, `npm install`, `npm run android:sync` сам. Якщо синхронізуєш через device_bash, git там лишає `.lock`-файли, поки не дано дозвіл на видалення.

## Правила гри
- Без чужих персонажів, логотипів і музики: гра йде в Google Play. Музика й звук генеруються кодом, графіка — піксель-арт кодом.
- Все модульне й легко замінне, особливо арт.
- Одна основна зброя. Біоми чергуються зі зростаючою складністю.
