# Slime Climb

Мобільна гра під Android: слизак стрибає між двома стінами і лізе вгору, автоматично відстрілюючись від ворогів.
Phaser 4 + Vite, обгортка під Android — Capacitor.

Специфікація v2 (поточна): `docs/superpowers/specs/2026-11-07-slime-climb-v2-design.md`
Специфікація MVP: `docs/superpowers/specs/2026-11-07-slime-climb-mvp-design.md`
План: `docs/superpowers/plans/2026-11-07-slime-climb-mvp.md`

## Як грати

Тап будь-де — слизак перестрибує на протилежну стіну (у польоті тапи ігноруються). Світ їде вниз, і що довше ти живеш, то швидше.
Слизак стріляє сам — у найближчого ворога на екрані. Уникай шипів, левів, кажанів і куль рослин: 3 життя, після удару 5 с невразливості, кожен новий рівень повертає одне життя.
За вбивства — досвід; на новому рівні обираєш 1 з 3 карток (швидкість атаки, урон, сповільнення).

На 2:00 — бос-павучиха «Твоя мамаша». За 4 с до неї карта очищається, з'являється плашка, під час бою немає ні шипів, ні звичайних ворогів.
- Фаза 1: стеж за тінню — вона показує, куди павучиха впаде на павутині.
- На 75% HP вона стає по центру вгорі, невразлива (смуга HP сіра), і випускає рій павучків. Рій летить на тебе, пролітає повз і повертається згори з +1 павучком (до 20). Дотик павучка — мінус життя й отруєння: 10 с слизак повільніший і болотного кольору. Коли рій знищено — знову фаза 1.
- На 35–40% HP — лють: павучиха червоніє, атаки швидші, музика напруженіша.
- Після перемоги 6 с тиші, далі вороги повертаються поступово.

## Запуск

Потрібен Node 22+.

```bash
npm i            # встановити залежності (один раз)
npm run dev      # дев-сервер з автоперезавантаженням, відкрий адресу з консолі
npm test         # автотести логіки (Vitest)
npm run build    # збірка в dist/
npm run smoke    # після build: відкриває гру в headless Chromium, ловить помилки, робить smoke.png
```

Для `npm run smoke` потрібен браузер Playwright: `npx playwright install chromium`
(або вказати свій Chrome змінною `CHROME_PATH`).

## Бот-плейтест

`node scripts/playtest.mjs --seconds 175` — бот грає справжню гру в headless-браузері (смерть вимкнена) і друкує:
удари за джерелом і часом, моменти, коли гравець з реальними життями помер би, старт і смерть боса, вибрані картки.
`--no-enemies` — лише шипи. Бот прогнозує рух на 2,5 с уперед, але не читає тінь боса, тож у бою з босом він слабший за людину.
Використовуй після змін у `balance.js`, щоб побачити, чи гра лишилась прохідною.

## Debug-параметри

- `?debug=1` — лічильник fps у кутку (на телефоні: `const DEBUG = true` у `src/main.js`).
- `?boss=1` — бос-павучиха з'являється на 6-й секунді замість 2:00 (підготовка з 2-ї).

Наприклад: `http://localhost:5173/?boss=1&debug=1`. Smoke з босом: `npm run smoke -- --query boss=1 --wait 9000`.

## Звук і музика

Усе синтезується кодом (WebAudio), файлів немає: ефекти — `src/systems/Audio.js`, мелодії записані нотами в `src/systems/Music.js`
(токен = 1/16: нота `A2`, `.` — тягнути, `-` — пауза, `x` — барабан). Музика грає від появи боса: тема бою → напружена в люті → фанфара перемоги → спокійна тема після боса.

## Android

Як зібрати APK і що перевірити на телефоні — `docs/android-build.md`.

## Баланс

Усі числа гри — у `src/config/balance.js`: швидкість прокрутки, життя, невразливість, параметри ворогів і боса, крива досвіду, картки, частота спавну.
Змінив число → `npm run dev` одразу покаже результат. Логіку з цими числами перевіряють тести (`npm test`): якщо змінив стартові значення, деякі тести, що фіксують їх, треба оновити.

## Структура

```
index.html            точка входу сторінки
src/main.js           конфіг Phaser, реєстрація сцен
src/scenes/           сцени (Boot генерує текстури-заглушки, Game — ігровий світ)
src/config/           числа балансу
src/systems/          чиста логіка без Phaser, покрита тестами
src/entities/         ігрові об'єкти
tests/                тести Vitest
scripts/smoke.mjs     smoke-перевірка в браузері
docs/superpowers/     специфікація і план
```
